HONGIK CAFE L자 시험 + 중간 급정지 / 2026-11-16

기본: 3.2m 직선의 절반 1.6m에서 급정지 → 실제 정지 1초 확인 → 재출발 → 회전 전 정지 → 우90° → 2.2m 직선 → 도착 정지 확인.
기본 12cm/s, L자 시험 상한 20cm/s. 거리 변경 시 급정지는 첫 직선의 절반으로 바뀝니다.
급정지는 즉시 0 속도 명령입니다. 물리 제동 성능을 보장하지 않습니다.

[적용]
1. 로봇을 정지시키고 기존 Windows 연결 창을 종료합니다.
2. 이 ZIP 전체를 새 폴더에 압축 해제합니다. 로봇과 같은 네트워크에 연결합니다.
3. Setup-Jetson.cmd 실행: Jetson 주소/SSH 암호로 기존 앱을 백업하고 새 서버를 설치합니다.
   설치 단계가 실패하면 시험을 시작하지 말고 오류를 확인하세요.
4. Install-HongikCafe.cmd 실행: Windows 바로가기도 새 패키지로 갱신합니다.
5. HONGIK CAFE 실행 → 지도·저장 지점 → 03 L자 시험.
6. 깊이 관측 연결 후 정상 상태를 확인합니다. 짧은 60cm/10초 검증으로 차체 응답을 먼저 확인합니다.
7. 전체 시험은 거리와 실제 빈 공간을 확인하고 급정지 체크를 켠 뒤 L자 시험 시작을 누릅니다.
   짧은 검증에는 중간 급정지를 추가하지 않습니다.

저장 지도/Nav2로 가는 경로가 아니라 현재 위치·방향 기준의 L자 경로입니다.
기존 지도와 수동 조종은 변경하지 않습니다. 장애물/센서 정지 조건도 유지합니다.
카메라 사각과 센서 오류 때문에 무조건 완주를 보장할 수 없습니다.
실제 Jetson에는 아직 적용하지 않았고 실물 주행 시험은 하지 않았습니다.
상세 변경·시험 범위는 L_TEST_20261116.md를 확인하세요.
