L자 15조건 실험 + 30cm 추가 회전 + 자동 DB / 배포 09 / 2026-11-16

EXPERIMENT_SETUP_20261116.md가 이번 배포의 기준입니다.
1. 로봇을 정지하고 기존 Windows 연결 창을 종료합니다.
2. 이 ZIP 전체를 새 폴더에 압축 해제합니다.
3. Setup-Jetson.cmd로 Jetson 서버를 업데이트합니다.
4. Install-HongikCafe.cmd로 Windows 바로가기를 갱신합니다.
5. 앱에서 ESP32 연결을 다시 시작하고 서보·IMU·영점·축 방향을 확인합니다.
6. 실험 세팅 열기에서 160cm 정지/S-curve 비율을 선택하거나, 03 L자 비교 실험에서 직진만 검증 후 20/30/40cm/s와 5조건 중 원하는 칸을 누릅니다.
7. 실험 기록 보기에서 정지 사유와 CSV/JSON을 확인합니다. 원본 DB는 Jetson runs/experiments.sqlite3입니다.

시작 버튼: 수평 상태 확인 → 첫 직선 → 중간 급정지 → 재출발 → 우90° → 두 번째 직선 → 정지.
기본 경로: 3.2m + 추가 30cm = 3.5m 후 회전, 두 번째 2.2m. 중간 정지 1.6m 유지.
15조건: 무보정 / 수평 / 능동 / S-curve / 능동+S-curve, 각 20/30/40cm/s.
전 비교 조건 ESP32 측정·영점·서보·방향 확인 필수. 매 실험 전 동일 출발점에 놓으세요.
기존 ESP32 보고 약 2Hz. 센서 실측 20Hz를 뜻하지 않습니다.
L자 자동 주행은 Jetson에서 실행되어 Windows 창 전환/화면 연결 단절에도 계속될 수 있습니다.
명시적 STOP/Space/Esc를 사용하세요. 네트워크 단절 시 원격 정지 전달이 지연될 수 있습니다.
접속 종료 버튼은 정지 요청도 전송합니다. 단순 네트워크 끊김은 취소하지 않습니다.
웹 서버가 종료/재시작되어도 이미 시작 확인된 L자는 Jetson에서 계속됩니다.
정지하면 주행 화면 위에 사유와 단계를 크게 표시합니다.
장애물·센서·USB 오류 정지는 유지됩니다. 무조건 완주를 보장하지 않습니다.
실물 Jetson 적용/주행/오르막 시험은 아직 수행하지 않았습니다.
ESP32 펌웨어는 자동 업로드하지 않습니다. 포함된 예측 펌웨어는 ESP32-S3 전용 핀 설정입니다.
reference의 core는 과거 백업 분석용입니다. 현재 Jetson 파일을 덮어쓰지 마세요.
