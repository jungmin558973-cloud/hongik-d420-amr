HONGIK CAFE / WINDOWS CLIENT / 2026.11.15

로봇을 켜고,
바탕화면에서 연결하세요.

지금 사용하는 주행·카메라·지도·트레이 앱을 Windows에서도 그대로 엽니다. ROS와 USB 센서는 Jetson에서 동작하고 Windows는 연결 창과 브라우저를 사용합니다.

로봇 전원 ON → K221 Wi-Fi → HONGIK CAFE 아이콘 → 앱에서 R · WASD

Windows에서 처음 한 번

  1. ZIP을 PC에 저장하고 모두 압축 풀기를 누릅니다.
  2. Install-HongikCafe.cmd를 더블클릭합니다.
  3. 바탕화면에 HONGIK CAFE 바로가기가 생성됩니다. 별도 Python·ROS·WSL 설치는 필요하지 않습니다.

설치 없이 실행하려면 같은 폴더의 Open-HongikCafe.cmd를 누르세요.

매번 사용할 때

  1. Jetson과 차체를 켜고 USB 연결을 확인합니다. Windows도 같은 K221에 연결합니다.
  2. 바탕화면 아이콘을 엽니다. 별도 SSH 창에서 seo 계정 암호를 입력합니다. 입력 글자가 안 보이는 것은 정상입니다.
  3. 브라우저에서 실차 수동 조종 화면이 바로 열립니다. R로 조종을 켭니다.
  4. WASD/방향키로 조종합니다. W+A/D는 이동하며 회전, A/D는 제자리 회전, Space/Esc는 정지입니다.
  5. 앱에서 정지 후 연결 창의 접속 종료를 누릅니다.

연결이 끊겼다가 복구돼도 이 실행기는 주행을 자동으로 시작하지 않습니다. 센서와 차체 준비 여부는 앱에서 확인하세요.

Jetson 담당자용

SJM에는 2026.11.15 최신 앱과 부팅 자동 시작 설정을 적용했습니다. 서버 업데이트나 재설치가 필요할 때만 Setup-Jetson.cmd를 실행하세요. 최신 앱과 자동 시작 서비스를 전송하고 기존 코드·지도를 보존합니다. 기존 ROS Humble과 센서 환경이 있는 SJM 대상입니다.

로봇 부팅 후 자동 서비스 실행과 실제 SSH 터널을 통한 카메라·지도·RViz 수신, 실차 수동 조종 화면 준비를 확인했습니다. 실제 Windows PC에서 연결 창을 실행하는 확인은 남아 있습니다. 이동 명령은 보내지 않았습니다.

연결이 안 될 때

먼저 Jetson 전원, 같은 K221, Jetson IP, SSH 창의 인증 메시지를 확인하세요. OpenSSH 클라이언트가 없으면 Windows 선택적 기능에서 설치합니다. Windows에는 SSH 서버가 필요하지 않습니다.

상세 사용법·진단 · Microsoft OpenSSH 안내

앱과 ROS는 Jetson에서 실행합니다. 연결만으로 로봇은 출발하지 않습니다. 한 명씩 조종하고, 사용 중에는 연결 창과 SSH 창을 열어 두세요.
