## 수정한 실패

- Windows 읽기 전용 파일 핸들의 fsync 오류 → 쓰기 가능한 핸들에서 확정.
- Windows 미리보기 파일 교체 잠금 → HTTP 응답 전에 파일 닫기, 일시 교체 실패는 캡처를 죽이지 않고 건너뛰기.
- mock start/tick 동시 접근 및 Windows 시계 분해능 → 제어 잠금, perf_counter와 중복 시각 허용. Jetson tick 지연 한도는 유지.
- device=0 추정 오류 → 실제 이름 탐색, C920 없거나 복수이면 자동 선택 거절, 실제 장치 이름/번호/해상도 저장.
- C920 format 설정 hang → 격리 워커 timeout 및 native 형식 기본. 다른 앱/서버는 유지.
