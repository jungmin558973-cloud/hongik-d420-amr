# 녹화 우선 실험실 사용법

바탕화면의 **홍익카페 실험실** 아이콘을 실행합니다. 노트북에 C920 USB를 연결하고 Jetson을 같은 Wi-Fi에 연결하세요. C920이 나중에 연결돼도 대기 중 자동으로 다시 검색합니다. 내장 ASUS 카메라로 대체하지 않습니다.

## 촬영

목표 속도 20/30/40cm/s와 조건을 선택하고 **실험 시작·녹화**를 누릅니다. 시작 클릭은 현장 통로, 컵 고정, 비상정지 준비 확인과 주행 승인을 뜻합니다.

영상·원시 로그 시작 확인 → 2초 사전 녹화 → 가속·정속 → 전진 오도메트리 1.6m에서 영속도 명령 → 실제 정지 확인 → 10초 추가 녹화 → 자동 저장합니다. 1.6m는 제동 명령 위치이며 실제 멈춘 위치와 초과 이동거리는 따로 남깁니다. 후진 복구는 기본 꺼져 있습니다.

트레이 OFF(A/B) 직선 촬영에는 과거 0.6m·12cm/s 검증 기록을 촬영 한도로 적용하지 않습니다. 사용자가 요청한 시험으로 기록하며 검증 완료 수치로 바꾸지는 않습니다. 트레이 LEVEL/PREDICTIVE(C–F)는 실제 트레이 연결과 별도 검증이 필요합니다.

장애물에 의한 자동 정지는 이 직선 촬영에서 비활성입니다. 수동 안전정지, 통신·오도메트리·녹화 장애에 의한 정지는 작동합니다. 정속 1.5초 조건 미달은 품질 경고로 기록하며 목표 위치 정지와 정지 후 관찰을 계속합니다. 실제로 중간에 멈춘 시험은 무효로 표시합니다.

## 영상·데이터

C920은 원래 지원하는 1920×1080 MJPG·30fps를 요청합니다. 실측 FPS와 누락 여부는 별도로 저장합니다. 촬영 중 실시간 OpenCV 분석을 중지하고 원본 녹화를 우선합니다. 최고 높이·RMS·최대 순간 이미지는 종료 후 **사후 정밀 분석**으로 만듭니다.

저장 위치는 이 프로그램 폴더의 **experiments**입니다. 화면의 **저장 폴더 열기 / 최근 실험 폴더**로 바로 확인합니다.

예: `experiments/2026-11-20/A_1.6m_20cmps/L1.60m_V20cmps_SOFF_TOFF_a0.2_d0.25_j0.5_Obs10s_촬영시각_고유번호_성공/`

1회차·2회차 대신 설정값·거리·촬영시각·성공 여부로 구분하고 덮어쓰지 않습니다. 각 폴더의 **실험설명서.md**에 모든 설정과 파일, 실제 결과와 실패 사유를 설명합니다.

- `webcam_raw.avi`: 원본 영상
- `camera_frames.jsonl`: 프레임별 실제 수신 시각
- `config.json`, `clock.json`: 설정과 시간 동기화
- `robot_raw.jsonl`, `robot_telemetry.jsonl`, `rosbag2/`: 실제 수집된 Jetson 데이터
- CSV·그래프·보고서·`completion.json`: 수집 결과와 물리 주행 완료 판정
- 사후 분석 결과: 최대 순간 이미지, 검출점, 액면 곡선, IMU/속도 전후 구간

실제 IMU/ESP32가 없으면 누락으로 표시하며 데이터를 만들어 넣지 않습니다. mm 단위는 길이 보정 후 사용합니다. 업로드 실패 시 로컬 원본을 유지합니다.

## 연결이 안 될 때

카메라 연결 대기는 C920 USB 장치가 Windows에 보이지 않는 상태입니다. Jetson 연결 대기는 SSH·제어 API·최신 오도메트리 중 연결이 없는 상태입니다. 연결이 확인되지 않으면 주행 성공으로 표시하지 않습니다. 바탕화면 실행기는 숨겨진 SSH 재연결 도우미를 띄우고, 앱은 C920을 주기적으로 재검색합니다.


## 영상 분석실

실험 화면 오른쪽 위 **영상 분석실 ↗**을 누르면 별도 탭으로 열립니다. 저장된 실험 선택 → **OpenCV 정밀 분석** → 최대 순간 이미지·상대 상승 높이·RMS·안정화 판정·실제 정지 위치를 확인하세요.

그래프를 클릭하면 해당 실제 시각의 원본 프레임으로 이동합니다. **이 순간으로 이동**은 최대 액면 상승 프레임을 선택합니다. 한 프레임씩 이동하며 검출된 초록 점을 직접 확인할 수 있습니다. 영상 분석 결과, 최대 이미지·검출점 CSV·주행/IMU 전후 구간·보고서는 원래 실험 폴더에 함께 저장됩니다.

기준면은 실제 정지 로그와 마지막 안정된 2초 이상 영상을 확인한 뒤 생성합니다. 옅은 파란 컵 벽·젖은 자국과 어두운 트레이를 제외하기 위해 사후 분석은 파란색 채도 하한 150, 명도 하한 60을 적용하며 **analysis_settings.json**에 사용 조건을 저장합니다. 원본 영상·roi.json·프레임 시각은 보존합니다. 검출 불가 구간을 보간하거나 높이를 만들어 넣지 않습니다. 안정화 시간이 비어 있으면 관찰 시간 내 ±2px·연속 1초 기준 충족을 확인하지 못한 것입니다. 제동·정지 구간 RMS는 전체 영상 RMS와 범위가 다릅니다.

실시간 촬영/수동 조종/저장 중에는 사후 분석 시작을 허용하지 않습니다. 분석 중에는 새 실험을 시작할 수 없습니다.


## S-curve 0~100과 분석 영상 재생

실험 화면의 S-curve 슬라이더 또는 숫자로 0~100을 선택합니다. 0은 기존 OFF, 100은 기존 ON이고 중간값은 가속도 변화의 완만함입니다. 적용 Jerk=설정 Jerk×100/강도이며 가속도·속도 상한은 유지됩니다. 급정지 명령은 부드럽게 처리하지 않습니다. 설정은 config.json·이벤트·설명서·폴더명 SC숫자에 기록됩니다. 서로 다른 중간 강도는 별도 조건 폴더로 저장합니다.

새 강도는 Jetson 최신 제어 모듈이 필요합니다. 바탕화면 실행기는 연결된 Jetson이 정지·비기록 상태일 때 이번 모듈을 반영합니다. 연결이 없으면 다음 연결 때 다시 실행하세요. 기존 모듈에서는 0/100 동작을 유지하며 중간 강도는 업데이트 필요로 표시합니다. 중간 강도의 실제 차체 응답은 첫 사용 시 실차 검증이 필요합니다.

영상 분석실의 **검출점을 표시한 영상 재생**에서 재생/일시정지와 0.25~2배 재생을 사용할 수 있습니다. 기존 분석 결과는 **재생용 영상 준비**를 한 번 누르세요. 새 정밀 분석은 H.264 재생 파일을 함께 만듭니다. 원래 프레임 시각 간격을 사용하고 그래프·최대 순간 이동과 연동됩니다. 원본 AVI와 분석 점 결과는 보존합니다. 생성 파일은 webcam_analysis_browser.mp4와 browser_video.json입니다.


저장 이름에는 밀리초 시각과 고유 ID가 들어갑니다. 같은 설정을 연속 실행해도 덮어쓰지 않으며, 기존 성공/실패 폴더와 충돌하면 다른 이름으로 보존합니다. 이전 종료된 실험의 로그가 통신 오류로 남으면 실제 정지와 로컬 종료 기록을 확인한 뒤 기록 종료·회수를 먼저 수행합니다.
