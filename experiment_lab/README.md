# HONGIK D420 실험·분석 프로그램 · 2026-11-21

이 프로그램은 기존 Jetson ROS2 Humble/HONGIK CAFE 환경을 재사용하는 내부 시험용 베타입니다. 기존 원격주행 소스를 덮어쓰지 않고 별도 실험·분석 경로를 추가합니다.

## ZIP 구성

- 프로그램 ZIP: 실험 앱·분석실·ESP32 펌웨어 소스·기존 앱 의존 소스/자산·설치/실행 스크립트·사용법·테스트 결과. 개인 키/암호/토큰/실험 데이터는 제외합니다.
- 데이터 ZIP: 실제 실험별 원본 영상·CSV·ROS 원시 데이터·검출 결과·최대 순간 이미지·그래프·설명서. 중복 ZIP과 개인 PC의 SQLite 색인은 제외합니다. 분석 결과를 전부 포함한 촬영과 분석 전 촬영을 모두 보존합니다.

## 기존 노트북

이미 설정된 노트북에서는 바탕화면 홍익카페 실험실을 실행합니다. 실험 화면의 영상 분석실 링크에서 저장 결과를 고르고 재생/분석합니다.

## 다른 Windows PC

1. 프로그램 ZIP을 쓰기 가능한 폴더에 해제하고 Python 3.12와 Windows OpenSSH Client를 준비합니다.
2. 폴더에서 아래 명령으로 설치합니다.

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

3. 실제 연결은 Connect-Real-Jetson.cmd로 초기 설정합니다. 팀원 본인의 SSH 인증과 호스트 키 확인이 필요합니다. 개인 노트북에 저장된 키/인증 정보는 배포하지 않습니다. 현재 설치 스크립트는 기존 Jetson 경로와 환경을 전제로 하므로 새 PC 수용시험이 필요합니다.
4. 설치된 가상환경에서 실행할 때는 다음을 사용합니다.

```powershell
.venv\Scripts\pythonw.exe scripts\launch_recording_lab.py
```

5. 데이터 ZIP을 불러오려면 프로그램의 experiments 폴더 아래에 날짜/조건/실험 폴더가 놓이게 압축을 해제합니다. SQLite 색인은 폴더 내 manifest.json에서 재구성됩니다. 데이터 ZIP에 사용자가 설정하지 않은 SSH 정보는 없습니다.

## 중요한 확인 범위

- 기본 실험: 선택 속도 20/30/40cm/s, 1.6m에서 급정지 명령, 실제 정지 확인 후 10초 녹화. 실제 정지 위치는 별도입니다.
- S-curve: 0=기존 OFF, 100=기존 ON. 중간 강도 소프트웨어 시험은 통과했으나 Jetson 새 모듈 적용과 실차 응답 검증이 필요합니다.
- 영상: C920 원본 1080p. 분석 높이는 px이며 mm는 아직 보정하지 않았습니다. 시각 동기화 오차와 검출 유효율을 함께 확인하세요.
- 실제 IMU/트레이가 없으면 미수신입니다. 수집되지 않은 값을 만들어 넣지 않습니다.
- 직선 촬영의 장애물 자동정지는 OFF입니다. 수동 정지와 통신·센서·녹화 장애 감시는 별도 유지됩니다.
