# 현장 검증 게이트 — 실차는 미검증

## 무구동 점검

- 원본 ZIP/서비스 설정/시리얼 소유자 복원 경로 확보. 차체 USB와 ESP32 USB를 식별한다.
- 모터 전원 물리 차단 담당자를 로봇 옆에 둔다. 소프트웨어 0 명령과 실제 제동 지연을 구분한다.
- 차륜을 들어 방향·속도 피드백·오도메트리 축·LiDAR TF·D435 source timestamp를 확인한다.
- C920e 점유/DSHOW/MSMF/분리/재연결/30fps·노출/저장공간을 확인한다.
- 고정 카메라에 정지 위치가 들어오고 액면/앵커 ROI가 실제 컵에 맞는지 직접 확인한다. 같은 깊이 보정 전 mm를 사용하지 않는다.
- STOP → 즉시 0 패킷, IMU/odom/scan/depth 지연 → 중단, Windows 종료 → Jetson 0.5초 watchdog, 외부 제어 충돌 → 중단을 모터를 띄운 상태에서 검증한다.
- bridge 프로세스 자체 강제 종료 시 펌웨어가 얼마나 오래 이전 명령을 유지하는지 측정한다. 독립 하드웨어 watchdog이 확인되지 않으면 무인 운전하지 않는다.

## 짧은 직선부터

- 통로/후방/사람/케이블 정리, 컵 고정, 서보 전원 확인, 시작점 보정, 현장 사용자 확인.
- 최초 A, .12m/s, .3m, 복귀 OFF. 새 제어기 실차 최초 검증임을 기록한다.
- .6m까지 거리/실측 정지위치/오차/브레이크 명령~완전 정지 지연을 측정한다. 기존 “급정지”는 물리 브레이크 피드백이 아니다.
- S-curve ON은 따로 검증한다. 시뮬레이션 jerk 제약이 실물 가속도/jerk 보장을 의미하지 않는다.
- 후진 후방 유효 빔·장애물·원점 오차·구동 시간 제한을 검증한 뒤 reverse 승인. 복귀 중 모의 장애물로 STOP 확인. 후진 출렁임 실험 데이터는 수집하지 않는다.
- 1.5m/2m, .20/.30/.40m/s 각각 검증 기록을 남긴 뒤 승인 한도 갱신. 30/40cm/s 미검증 항목은 큐 대기 유지.

## 트레이 및 반복 시험

- OFF는 PWM 유지이며 전원 차단이 아니다. LEVEL은 영점/방향/IMU/실제 mode4를 확인한다.
- PREDICTIVE는 PROTO=2, 두 서보 enabled, direction_checked, zero_saved, route ACK, 실제 예측모드 확인. 각도·각속도·lead·gain을 낮게 검증한다. PWM은 실측 축 각도가 아니다.
- 출렁임 보상 중에도 STOP을 지연하지 않는다. 예측 제어가 실패하면 주행을 중단한다.
- 각 반복마다 컵 수위/카메라·ROI/원점/전후방 안전 상태를 재확인하고 새 ARM/시작. 다음 실험으로 무인 자동 진행하지 않는다.
- 갑작스러운 장애물 시험은 신호 주입 또는 안전한 모형으로 수행한다. 사람을 튀어나오게 하지 않는다.
- 추천은 기록된 반복 근거를 검토하여 설정 초안에만 적용한다. 새 파라미터도 독립 commissioning 대상이다.
