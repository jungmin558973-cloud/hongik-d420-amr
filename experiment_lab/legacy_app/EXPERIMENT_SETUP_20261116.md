# 배포 09 · 실험 세팅과 160cm 정지 목표

주행 화면의 **실험 세팅** 링크로 별도 화면을 연다. 속도 20/30/40cm/s, S-curve 0~100%, 회전 최고 각속도 0.4/0.6/0.8rad/s와 트레이 종류를 선택한다.

- **출발 → 160cm 목표 정지 시험**: 현재 위치를 0으로 삼아 160cm 부근에 정지하도록 계획한다. 회전·재출발은 하지 않는다. 0%는 계산된 지점에서 즉시 0 속도 명령을 보낸다.
- **이 세팅으로 L자 실험**: 기존 3.2m+30cm → 우90° → 2.2m 경로에 선택한 감속·회전 설정을 적용한다.
- S-curve 100%는 기존 계획 감속 시간, 중간 %는 그 시간을 비례 축소한다(최소 0.1초). 0%는 즉시 0 명령이다. %는 시간 비율이며 토크·효율·액체 안정성 %가 아니다. 장애물·센서 정지에는 완만한 감속을 강제하지 않는다.
- 차체만은 ESP32 없이 실행 가능하며 기존 트레이 상태를 변경하지 않는다. 무보정 비교 조건과 다르다. 센서가 없으면 각도는 미측정이다. 수평/능동 선택은 기존 ESP32 준비 검사를 사용한다.

## 160cm 정지 계산

최초 급정지 시험은 `v²/(2a) + v·지연 + 0.02m`의 예상 제동 거리를 현재 보고 속도로 계산한다. 기본 가정 a=0.5m/s², 지연=0.10초다. **실차 측정치가 아니며 첫 회의 160cm 정확 정지는 보장하지 않는다.** 실제 제동·노면 마찰·하중에 따라 선을 넘거나 앞에 멈출 수 있으므로 실험선 뒤에도 공간을 확보한다.

정지 명령 지점과 속도, 실제 정지 위치, 목표선 오차를 기록한다. 장애물/센서 개입 없는 완료된 급정지 시험만 유효 감속도 보정 자료로 사용한다. 다음 같은 속도(±3cm/s) 시험은 DB의 최근 유효 실측 제동 거리로 모델을 갱신한다. 지연을 포함한 유효 감속도이므로 재사용 때 별도 지연을 중복 더하지 않는다. S-curve 시험은 급정지 보정에 섞지 않는다. 하중·바닥·배터리 조건을 바꿨다면 재사용 체크를 해제하고 새 검증을 한다.

S-curve 시험은 프로파일 적분 거리로 160cm 목표 감속을 시작한다. 계획 속도와 실제 차체 속도는 같다고 보장하지 않는다. 실제 선 오차는 별도로 기록한다. 실제 위치는 바퀴/차체 오도메트리 기준이며 바닥 줄자/외부 카메라로 검증해야 한다.

## 회전 개선

사용자가 제공한 제조사 CODBOT 4WD 통신 문서의 0x01은 선속도·각속도 명령이다. 회전 토크/전류를 직접 지정하는 필드는 없다. 문서의 각속도 전송 범위 0~5.4rad/s는 하중을 올린 D420의 권장 실차 회전 속도가 아니다. 다른 제조사의 모터 토크 값을 적용하지 않았다.

기존 L자 최고 0.20rad/s에서 기본 **0.60rad/s**로 상향하고, 0.4/0.6/0.8 선택을 제공했다. 각속도 변화율을 제한하고 남은 yaw 오차에 따라 감속한다. 실제 회전각과 회전 종료 정지를 확인한 뒤 다음 직선으로 진행한다. 회전 중심이 시작점에서 15cm 이상 이동하면 정지해 바닥·하중·구동 상태를 확인하도록 한다. 토크 증가나 미끄러짐 해결을 보장하는 변경이 아니다. 실물 회전 및 적정 속도는 미검증이다.

## 적용과 공동 작업

로봇 정지 → 새 ZIP 전체 해제 → Setup-Jetson.cmd → Install-HongikCafe.cmd → 앱 다시 연결. ESP32 펌웨어는 이번에 변경하거나 자동 업로드하지 않는다. 15조건 비교·DB 기록의 기본 설명은 EXPERIMENT_15_CASES_20261116.md를 참고한다.

GitHub에는 편집 가능한 소스를 보관한다. 협업자는 main 최신본에서 작업 브랜치를 만들고 PR로 변경 내용을 공유한다. 실차는 main 변경만으로 자동 배포하거나 출발하지 않는다. 실험 DB와 비밀번호·키는 저장소에 올리지 않는다. 완전한 Windows 설치 파일에는 외부 라이브러리/자산과 Jetson payload가 필요하므로 전체 ZIP을 사용한다.

검증: 자동 시험 49개 및 Edge 브라우저 시험 1개 통과. 160cm 단독 정지, 3개 속도, S-curve 비율, 빠른 회전/종료, ESP32 없는 차체 시험과 기존 15조건·DB·센서 정지 검사 포함. 실제 배포·정지 거리·회전 성능은 미검증이다.
