# 배포 10 · HONGIK CAFE 내부 실험 탭

상단 메뉴 **05 실험 세팅 · 160cm**를 누르면 HONGIK CAFE 내부에 실험 설정을 표시한다. 외부 탭/창으로 이동하지 않는다. 기존 직접 주소도 유지한다. 바탕화면 바로가기는 연결 후 이 탭을 기본으로 연다. 06 실험 기록에서 CSV/JSON을 내려받는다.

160cm 정지/S-curve·속도·회전 설정 및 센서 기록은 EXPERIMENT_SETUP_20261116.md와 같다. 이번 배포는 제어기/서보의 정격이나 모터 토크를 변경하지 않는다.

## 불필요한 장애물 정지 축소

- 고정 여유 거리를 8cm에서 **5cm**로 축소했다.
- 전후 방향 제동 여유를 좌우에도 동일하게 붙여, 직진 경로 밖 의자/물체 때문에 정지하던 과도한 폭을 제거했다. 좌우 실제 차체 폭 + 5cm 및 회전 궤적 검사는 남긴다.
- 전진 예측 구간은 1초에서 **0.45초**로 줄였다. 허용 깊이 시각 지연 0.35초와 제어/전송 반응 0.10초를 합친 모델이다. 제자리 회전은 1초 궤적을 유지한다.
- 전방은 여전히 현재 보고 속도에 따른 제동거리 v²/(2×0.25m/s²)를 추가한다. 이 감속도는 검증 모델이며 실물 제동 보장치가 아니다. 40cm/s일 때 모델 제동 여유 32cm, 고정 여유 5cm, 반응 중 이동 약 18cm를 검사하므로 5cm까지 접근한 후 정지하는 설정이 아니다.
- 장애물이 사라져 다음 제어 주기의 궤적이 통과하면 바로 재개한다. 별도의 장애물 통과 후 대기 시간을 추가하지 않는다. 깊이 센서 지연 후 복구는 별도의 정지 확인/새 프레임 검사다.

장애물 감지 자체, 센서/USB 오류 정지, 명시적 STOP은 끄지 않았다. 전방 카메라의 측후방 사각은 그대로이므로 사람과의 충돌 방지나 실제 5cm 정밀 거리 유지를 보장하지 않는다. 수정 후 빈 공간에서 낮은 속도로 실제 여유 거리와 감속 응답을 확인해야 한다. 이전 설정으로 측정한 실험과 새 설정의 실험은 장애물 정책이 다르므로 배포 버전으로 구분한다.

자동 시험 52개, Edge 통합 브라우저 시험 1개 통과. 15조건 경로·160cm 정지·감속·DB·센서 정지와 함께 5cm 정적 경계, 속도별 전방 제동 여유, 경로 밖 측면 물체, 장애물 해제 다음 주기 재개를 검사했다. 실물 여유 거리와 제동 성능 검증은 별도다.
