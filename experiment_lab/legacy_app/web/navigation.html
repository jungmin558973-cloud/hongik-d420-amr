03 L자 비교 실험 · 15조건

ESP32 연결·영점 설정 열기 ↗

ESP32 상태 확인 중

20 / 30 / 40cm/s × 5조건

선택한 조건으로 L자를 1회 실행하고 자동 기록합니다. 매 시험 전 동일 출발 위치·방향으로 로봇을 놓으세요. 전 조건 중간 정지 포함. S-curve는 계획 정지에만 적용하며 장애물 정지는 즉시 수행합니다.

조건 목록 확인 중

무보정 = 서보 PWM 고정. 모든 비교 조건은 ESP32 측정·영점·방향 확인이 필요합니다. 기존 상태 보고 약 2Hz로는 급격한 각도 변화의 최대값을 놓칠 수 있습니다.

현재 위치·방향에서 직진 → 중간 급정지 → 재출발 → 정지 확인 → 오른쪽 90° → 직진 → 정지 확인
첫 직선 3.2m + 추가 0.3m / 두 번째 2.2m는 임시값 · 실제 거리에 맞게 수정
저장 지도·라이다 장애물 판정 미사용
전방 깊이 기반 감속·정지 / 작은 방향 보정
측후방은 카메라로 보이지 않습니다.
전체 경로: 입력한 두 직선 거리와 오른쪽 90° 회전
짧은 검증: 최대 12cm/s · 직진 60cm·10초 후 정지 · 중간 급정지 제외
Jetson 내부에서 센서로 제어합니다. L자 자동 주행은 창 전환·화면 연결 단절만으로 중단하지 않습니다. 멈추려면 정지 버튼/Space/Esc 또는 현장 정지 수단을 사용하세요. 수동 조종의 창 이탈 정지는 유지합니다.

기본: 첫 직선 3.2m + 추가 0.3m = 3.5m 후 회전. 중간 급정지 지점은 기존 첫 직선의 절반을 유지합니다.

급정지는 감속 램프 없이 0 속도를 명령합니다. 물리 제동 거리와 바퀴 정지는 실측해야 합니다. 기본 12cm/s · 최대 40cm/s. 장애물·깊이 단절 시 정지 기능 유지.

기본 동작: 실제 수평(±1°) 확인 후 L자 시험 시작. 급정지 예측 기울이기는 아래에서 선택합니다.

먼저 주행·트레이 제어실에서 ESP32 연결 → 서보 켜기 → 실제 수평 영점 → 방향 확인 → 수평 유지로 준비하세요. 예측용 PROTO=2 펌웨어가 필요합니다. 선행 보정 축/부호는 기존 예측 설정을 사용합니다. 차량 가속도 IMU를 사용한 예측은 아닙니다.
