# 촬영·정밀 분석 추가 조건

1. 자동 전진만 본시험으로 인정한다. 거리/속도/가속도/감속도/jerk 설정이 목표 속도에서 정속 1.5초 이상을 허용하지 않으면 출발 전에 거절한다. 실제 odom 속도가 목표의 ±5%(저속에서 최소 ±.005m/s) 범위에서 1.5초 이상 유지됐는지도 확인한다. 일찍 멈추거나 안전정지한 시험은 무효이며 재출발하지 않는다.
2. 원시 프레임의 실제 해상도가 3840×2160 이상이어야 한다. 요청한 해상도/확대 저장은 근거로 사용하지 않는다. C920e는 공식 최대 1920×1080/30fps이며 현재 연결은 640×480이다. 현재 장비 기록은 4K 본시험이 아니다.
3. 실제 원시 ROS IMU 또는 ESP32 트레이 상태를 `imu.csv`로 추출한다. 미연결이면 헤더만 있는 CSV와 availability=false를 기록한다. 트레이 Roll/Pitch와 차체 가속도/각속도를 구분하며 없는 신호를 만들지 않는다. 실제 Jetson sidecar 갱신/ESP32 연결은 현장 적용이 필요하다.
4. 각 동일 조건에서 유효 시험 3개가 필요하다. `/api/research-protocol`에서 실제 유효 run_id와 무효 run_id를 분리한다. 큐의 무효 결과는 INVALID_PROTOCOL로 표시하여 완료 3회에 세지 않는다. 조건별 시작은 현장 확인/ARM 후 진행한다.
5. 최종 제동은 거리 기반 자동 프로파일로 한 번 수행한다. 실측 정지위치가 목표 ±5cm 이내인지 확인하고, ZERO_COMMAND/STOP_CONFIRMED가 각각 한 번 있어야 한다. 초록선과 로봇 기준점을 현장에서 odom 원점/진행축에 등록해야 하며, 바닥선 사진만으로 자동 정지위치를 아는 기능은 없다.

## 액면 점 기반 지표

ArUco 4×4_50 보드로 탐색 창을 제한하고 가장 큰 파란 연결 영역의 각 열에서 상단 경계를 얻는다. 국소 색상 임계 교차점의 보간은 해상도를 늘리거나 정확도를 보장하지 않는다. 5열 국소 이상점 제거를 사용하고 넓은 봉우리를 직선으로 펴지 않는다. 초록 점=유효 원시 검출점, 빨간 점=제외점, 노란 곡선=비교용 샘플 곡선이다.

정지한 최초 15프레임의 열별 기준면을 저장하고 정규화 101개 위치와 대응한다. 3픽셀을 넘는 결측 구간은 유효점으로 보간하지 않는다. 원시 점, 유효성, 열별 편차, 프레임별 공간 RMS와 peak-to-peak를 JSONL/CSV에 보존한다. 시험 RMS는 모든 유효 표면점 편차에서 계산하며, 최대 상승/최대 절대 편차/가시 파란 영역 높이를 구분한다.

컵 바닥의 실제 기준점과 같은 평면의 길이 보정이 없으므로 `maximum_height_mm`는 null이다. 보드와 액체가 다른 깊이에 있어 보드 격자만으로 정확한 mm를 주장하지 않는다. 카메라/트레이 회전, 3D 액면의 앞·뒤 경계, 가림은 실제 영상으로 추가 검증해야 한다.

## 텔레옵

실험실 앱에 WASD/방향키·Space/Esc·속도/회전 슬라이더를 추가했다. 기존 `/api/teleop-start`, `/api/teleop-input`, owner/control_id/sequence를 재사용하며, 입력 소실·blur·화면 숨김·소유권 충돌에서 정지한다. 기본 .12m/s/.30rad/s, 확장 범위는 현장에서 직접 선택하고 새 ARM을 해야 한다. 1.50m/s/5.40rad/s는 기존 앱 입력 상한으로 실제 브리지 한도나 실측 안전 검증값이 아니다. 수동 정지 기록은 본시험 조건을 통과하지 못한다.

## 검증 및 적용 범위

자동 검사 43개 통과(전체 재실행). 키보드 제어는 가짜 upstream으로만 검증했고 실제 이동 명령은 보내지 않았다. Windows 앱에는 반영했다. 현재 원격주행 서비스 연결이 끊겨 있고, 신규 거리 제어 어댑터의 실차 적용/현장 검증 및 4K 장비·IMU 연결은 남아 있다.
