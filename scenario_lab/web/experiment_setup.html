실험 세팅

지도·L자 화면 · 저장된 실험 기록
차체만 시험은 ESP32 없이 가능하며 트레이 제어 상태를 바꾸지 않습니다. 각도 자료가 없으면 미측정으로 저장합니다. 0%: 계산한 지점에서 즉시 0 속도 명령. 100%: 기존 완만한 S-curve. 중간 값은 감속 시간을 비례 조절합니다. 장애물 정지는 항상 우선합니다. 토크 설정이 아닙니다. 목표 각도 근처에서 감속하며 중심이 15cm 이상 밀리면 정지합니다.
첫 급정지 시험의 제동 모델

첫 회는 이 가정과 0.10초 지연, 2cm 여유로 정지 명령 지점을 계산합니다. 실제 보장값이 아닙니다. 이후 동일 속도의 정상 급정지 시험에서 측정된 제동 거리로 갱신합니다. 하중·바닥·배터리를 바꿨다면 ‘기존 보정 사용’을 해제하세요.

L자 기본: 3.2m + 30cm 후 우90° → 2.2m. 각 시험은 현재 위치·방향에서 시작합니다. 첫 검증은 빈 공간에서 낮은 속도로 실시하세요.

상태 확인 중

시작 명령이 수락된 뒤에는 Jetson에서 주행·기록합니다. 창 닫기/화면 연결 단절만으로 취소하지 않습니다. 센서/장애물 오류 정지와 STOP은 유지합니다.
