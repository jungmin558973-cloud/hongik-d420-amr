03 L자 시험 · 중간 급정지

현재 위치·방향에서 직진 → 중간 급정지 → 재출발 → 정지 확인 → 오른쪽 90° → 직진 → 정지 확인
3.2m / 2.2m는 임시값 · 실제 거리에 맞게 수정
저장 지도·라이다 장애물 판정 미사용
전방 깊이 기반 감속·정지 / 작은 방향 보정
측후방은 카메라로 보이지 않습니다.
전체 경로: 입력한 두 직선 거리와 오른쪽 90° 회전
짧은 검증: 최대 12cm/s · 직진 60cm·10초 후 정지 · 중간 급정지 제외
노트북 통신 지연 중에도 Jetson 센서로 제어합니다.

급정지는 감속 램프 없이 0 속도를 명령합니다. 물리 제동 거리와 바퀴 정지는 실측해야 합니다. 기본 12cm/s · 최대 20cm/s. 장애물·깊이 단절 시 정지 기능 유지.
